# 02 — Синк ролей в платформенные форматы

**Требования:** R14i
**Зависит от:** 01
**Зона:** `team/sync.mjs` · `.claude/agents/` · `.github/agents/` · `.agents/`
**Волна:** 2
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

`bun team/sync.mjs` читает `team/roles/*.md` и генерирует точки запуска ролей для
трёх платформ: `.claude/agents/triptrek-<role>.md`, `.github/agents/triptrek-<role>.agent.md`,
`.agents/skills/triptrek-<role>/SKILL.md`. `bun team/sync.mjs --check` падает с
exit 1, если сгенерированные файлы разошлись с источником. Правка роли делается
один раз — в `team/roles/`.

(обязательно к прочтению первым; форматы сняты с файлов v1, см. также `notes.md` §5).

## Критерии приёмки

- [ ] sync.mjs — bun-скрипт без зависимостей; вход — только `team/roles/*.md`
- [ ] Генерирует все шесть ролей во все три формата; тело роли общее, различается frontmatter и обёртка
- [ ] `--check`: расхождение → exit 1 с именем файла; совпадение → exit 0
- [ ] Идемпотентен: два запуска подряд не меняют файлы
- [ ] Сгенерированные файлы помечены шапкой «сгенерировано из team/roles/, не править»
- [ ] Старые роли v1 в `.claude/agents/` и `.github/agents/` замещены новыми (после архивации в T01)
- [ ] `bun team/sync.mjs --check` зелёный после генерации
