# ADR-0003: Хранилище файлов — S3-совместимое с первого дня

Статус: принято · 2026-09-09

## Контекст
Фото — ключевой контент (99% пользователей — телефоны). Дисковый volume завязывает данные на одну машину и лишает CDN; политика файлов (EXIF/GPS, лимиты, сниффинг) была размазана по трём маршрутам и местами отсутствовала — GPS с фото утекал в публичный URL.

## Решение
Один storage-модуль: интерфейс `put/remove`, политика (magic-byte, лимиты по kind, UUID-имена, sharp-обработка с выпиливанием EXIF; оригинал не сохраняется) — внутри модуля. Два adapter: `disk` (dev) и `s3` (прод, S3-совместимый API: R2 / Яндекс / Selectel — только env). Раздача — публичные URL bucket-а через собственный домен; имена UUID непредсказуемы, доступ к приложению проверяется отдельно.

## Последствия
- Приватная раздача (проверка членства) — отложена; текущий уровень приватности не ухудшается.
- Egress-трафик дешевле у R2 (бесплатно); выбор провайдера — env, не код.
