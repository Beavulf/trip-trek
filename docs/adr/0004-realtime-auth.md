# ADR-0004: Realtime — аутентификация на handshake, publish-интерфейс

Статус: принято · 2026-09-09

## Контекст
`/emit` и socket.io handshake не проверяли личность: любой мог подписаться на события чужой поездки, разослать поддельные события и массово дёрнуть Web Push. Комнаты — в in-memory Map без проверок.

## Решение
JWT проверяется на handshake; `trip:join` — после проверки членства в БД. Сокет — read-only канал (клиентские события, кроме join/leave, игнорируются); все мутации — через HTTP API. Сервер публикует события через один интерфейс `publish(tripId, event, payload)` (синглтон io на globalThis — Next и server.ts в одном процессе, HTTP-мост `/emit` удалён). Transport-adapter: socket.io сейчас, socket.io-redis — при втором инстансе.

## Последствия
- Спуфинг событий и push-спам закрыты на входе.
- Горизонтальное масштабирование = добавить Redis-adapter, код publish не меняется.
