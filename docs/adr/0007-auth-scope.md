# ADR-0007: Auth на запуск — e-mail+пароль, без SMTP/OAuth

Статус: принято · 2026-09-09

## Контекст
Аудитория ≤500 «своих» пользователей; инфраструктуры e-mail нет. Подключение SMTP/OAuth до запуска отодвигало бы деплой без пропорциональной пользы.

## Решение
На запуск: только существующая регистрация по e-mail+паролю (JWT 30d). Сброс пароля — вручную владельцем через БД. SMTP-сброс владелец поднимет позже на своём VPS; OAuth — после запуска. Дублирующую сессию NextAuth `[...nextauth]` + custom-login консолидировать при первом касании auth-кода (один путь выпуска JWT).

## Последствия
- JWT не отзывается до истечения: при компрометации — ждать 30 дней или ротация `NEXTAUTH_SECRET` (разлогинивает всех).
- SMTP/OAuth — отложенный скоуп, не отменяет решений ADR-0004 (handshake читает тот же JWT).
