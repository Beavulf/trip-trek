# ADR-0008: Деплой с VPS и наблюдаемость — минимум

Статус: принято · 2026-09-09

## Контекст
Solo-разработка; цель — воспроизводимый деплой без лишних движущихся частей, с возможностью диагностировать инцидент.

## Решение
Деплой: `git pull && docker compose up -d --build` на VPS (GitHub Actions + registry — когда надоест руками). Домен — Cloudflare DNS; сперва DNS-only, затем прокси + Full (strict). Наблюдаемость на запуск: logger с уровнями (JSON в prod), `error.tsx`/`global-error.tsx`, честный `/api/health` с db-ping, typecheck gate в сборке. Sentry — после первых реальных пользователей (logger — его точка входа).

## Последствия
- Инциденты первых недель диагностируются по `docker logs` + health; этого достаточно при одном инстансе.
