# ADR-0012: Приём донатов через WebMoney Merchant

Статус: принято · 2026-11-05

## Контекст

Копирование WMZ-кошелька — обычный перевод: приложение не узнаёт надёжно, что деньги пришли, и не может автоматически привязать их к аккаунту. Требуется вариант поддержки с подтверждением платежа от платёжной системы, без поиска email в комментарии.

## Решение

1. Авторизованный пользователь создаёт заказ на сумму от $1 до $200. Сервер связывает заказ с его аккаунтом, создаёт уникальный номер платежа и подписывает форму SHA256 с Secret Key X20. Ограничения проверяются и в браузере, и на сервере.
2. Форма отправляется в WebMoney Merchant. Result URL задаётся статически в кабинете Merchant, а переопределение URL из формы отключается. Предварительный запрос включается; проверка заказа отвечает `YES` только для ожидающего заказа с точной суммой, своим WMZ-кошельком и рабочим режимом.
3. Итоговый callback принимается только при корректной SHA256-подписи, совпадении кошелька, суммы, номера заказа и рабочего режима. Возврат браузера на Success URL не является подтверждением оплаты.
4. Одна транзакция БД помечает заказ оплаченным и создаёт `Donation` с `source="webmoney"`, связанный с аккаунтом заказа. Уникальность номера заказа и номера транзакции предотвращает повторный учёт; повтор того же callback получает `YES`, но не создаёт вторую запись.
5. Secret Key и Secret Key X20 хранятся в `AppSettings`; админский API отдаёт только замаскированные хвосты. В логе сохраняется только факт наличия секретов. Секреты не помещаются в публичный API или браузерную форму.
6. Ручной перевод на WMZ-кошелёк и DonationAlerts остаются доступными. Только Merchant-платёж автоматически создаёт запись и бейдж.

## Последствия и настройка

- Требуется применить миграцию `20261105114000_webmoney_merchant`, указать Z-кошелёк и оба Merchant-секрета в админке → Настройки.
- В кабинете Merchant для этого кошелька нужно задать SHA256, включить обязательную подпись платёжной формы, включить предварительный запрос, отключить передачу/переопределение Result URL из формы и указать показанный админкой Result URL.
- Успешные платежи в рабочем режиме создают донат в валюте USD. Тестовые (`LMI_MODE=1`) намеренно не записываются и не выдают бейдж.
- До настройки Merchant и проверки callback на тестовом аккаунте реальную оплату включать нельзя. Merchant может отдельно ограничивать сумму и доступные способы оплаты.
