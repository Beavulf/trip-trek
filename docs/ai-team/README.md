# Команда разработки и развития TripTrek

Единый рабочий процесс для Claude Code и Copilot в VS Code. Его запускает проектный
skill `/triptrek-team`; ролевые агенты описаны в `.claude/agents/` и
`.github/agents/`. Техническая карта проекта остаётся в [AGENTS.md](../../AGENTS.md)
и [docs/architecture.md](../architecture.md).

## Участники

| Роль | Ответственность | Может менять продуктовый код |
|---|---|---|
| Product Strategist | Выясняет проблему и аудиторию, проверяет гипотезы, альтернативы, сильные и слабые стороны, формулирует успех и границы | Нет |
| Solution Architect | Исследует текущую архитектуру, готовит спеки, ADR и план работ с зависимостями | Нет |
| Implementation Engineer | Выполняет только одобренные таски, тесты и нужные обновления документации | Да, только в рамках таска |
| Quality Reviewer | Независимо проверяет изменения, требования, регрессии, доступность и потенциальные уязвимости | Нет |
| Growth & Feedback Analyst | Анализирует доступные метрики и отзывы, предлагает стратегию и готовит черновики маркетинговых/пользовательских текстов | Нет; ничего не публикует и не отправляет |

Координатор — основной агент текущего диалога: он ведёт вопросы, требования,
передачу работ и итоговую приёмку. Используй отдельную роль для узкого анализа;
не запускай всех специалистов «на всякий случай».

## Жизненный цикл

`idea → discovery → spec → plan → approved → implementation → review → accepted → release-ready → measured`

1. **Идея:** зафиксировать исходную формулировку и не потерять ни одно требование.
2. **Discovery:** уточнить аудиторию, проблему, контекст, ограничения, альтернативы,
   сильные/слабые стороны и гипотезы; при необходимости задать вопросы владельцу.
3. **Спецификация:** изучить релевантные части репозитория и подготовить поведение,
   состояния ошибок/пустых данных, критерии приёмки, аналитику и влияние на архитектуру.
4. **План:** разбить работу на небольшие таски с файлами, зависимостями, проверками и
   назначенной ролью. Для значимых решений записать ADR.
5. **Одобрение:** до реализации показать спецификацию и план. Работа начинается только
   после явного одобрения владельца; подтверждение можно дать на все таски или на
   конкретную очередь.
6. **Разработка:** координатор передаёт готовые таски Implementation Engineer. Агент
   работает локально и в назначенном объёме. После каждого таска координатор собирает
   результат и направляет изменения на независимое ревью.
7. **Приёмка:** проверить критерии, тесты, lint/build по масштабу изменения, документацию,
   известные ограничения и ручные шаги. Не заявлять, что функция принята, если проверки
   не выполнены.
8. **Подготовка релиза:** выдать чеклист релиза, риски/откат, черновик анонса и план
   измерения результата. Деплой, merge, публикации и отправка писем остаются за владельцем.
9. **Измерение и поддержка:** после релиза сравнить согласованные метрики, сгруппировать
   отзывы/ошибки, отделить факты от гипотез, предложить приоритеты и подготовить ответы
   пользователям на проверку владельца.

Шаблоны брифа, спеки, таска, релиза и разбора отзывов находятся в
[`.claude/skills/triptrek-team/templates/`](../../.claude/skills/triptrek-team/templates/).

## Передача тасков и пределы автономности

После одобрения плана координатор может сам распределить готовые таски по ролевым
субагентам, отслеживать их завершение и передать результат ревьюеру. Это не фоновый
наблюдатель файлов: Claude Code и Copilot не будут сами просыпаться от появления нового
файла в очереди. Для нового прогона нужен запрос владельца или явный запуск skill.

Агенты не делают `git push`, merge, deploy, миграций на проде, публикаций в соцсетях,
рассылок и ответов пользователям без отдельного явного разрешения на конкретное действие.

triptrek.team@gmail.com.

Наличие Метрики в приложении не означает доступ к её кабинету или данным. До настройки
отдельного безопасного подключения аналитик работает только с локальным кодом,
публичными источниками или обезличенным экспортом, который предоставил владелец.
См. [политику доступа](data-access.md); не вставляй секреты в чат или репозиторий.
