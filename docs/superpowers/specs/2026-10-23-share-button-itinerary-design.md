# Дизайн: кнопка «Поделиться» в hero маршрута

Дата: 2026-10-23. Статус: одобрено пользователем (выбран вариант «окошко»).

## Задача

На вкладке «Маршрут» в hero-блоке кнопка «На карте» заменяется на «Поделиться»,
которая даёт быстрый доступ к публичной странице `/p/<token>` («живой журнал»:
фото + маршрут для гостей без входа). У героев три кнопки: «Добавить день»,
«На карте» (ярлык на вкладку Карты) и PDF-иконка. Карта не теряется — вкладка
есть в нижнем таб-баре, поэтому ярлык может уступить место шерингу.

Вся механика публичной страницы уже есть: API `/api/trip/share`
(включение/rotate/`shareAllowDownload`, гард `requireTripOwner`), гостевые
роуты `/p/[token]/*`, карточка управления `PublicShareSettings` в окне
«О поездке». Нового бэкенда нет: ни API, ни схемы, ни realtime-событий.

## Поведение

Кнопка «Поделиться» (иконка `Share2`) видна только владельцу поездки — API
шеринга и сейчас пускает только его (`requireTripOwner`), остальным участникам
остаётся «На карте». Тап открывает нижний шит «Поделиться поездкой»
(`MobileBottomSheet`, «назад» на телефоне закрывает его):

- **Ссылка включена**: превью ссылки + кнопка «Скопировать» (clipboard + тост),
  широкая кнопка «Поделиться…» — `navigator.share` (системное меню на телефоне);
  где API нет (Firefox на ПК) или вызов упал — фолбэк «скопировать + тост».
  Ниже — переиспользованная карточка `PublicShareSettings` (тумблер вкл/выкл,
  «гости могут скачать фото», «новая ссылка»).
- **Ссылка выключена**: пояснение («живой журнал только для чтения: фото и
  маршрут, без денег и чата») + первичная кнопка «Включить и поделиться» —
  POST `enabled: true` (сервер генерирует токен), шит перерисовывается.
- **Загрузка** — спиннер; **ошибка** — надпись + кнопка «Повторить» (refetch).

Отмена системного меню (`AbortError`) — молча, без тостов.

## Компоненты

| Файл | Действие |
|---|---|
| `src/lib/share-action.ts` | новый: чистый `resolveShareAction(nav)` → `"native" \| "clipboard"` + тест рядом |
| `src/hooks/trip/use-public-share.ts` | новый: TanStack Query над GET/POST `/api/trip/share`; ключ `["trip-share", tripId]`; наружу `state/url/update/isLoading/isError/refetch` |
| `src/components/trip/trip-public-share.tsx` | рефакторинг без смены UI: ручной fetch/useEffect → хук |
| `src/components/trip/share-trip-sheet.tsx` | новый: шит с кнопками «Скопировать»/«Поделиться…» + `<PublicShareSettings/>` |
| `src/components/trip/itinerary/Itinerary.tsx` | замена кнопки; `isOwner` как в `trip-info-sheet`: `trip.participants` × `useAuth()` |

Карточка в «О поездке» остаётся — два входа, одна логика (хук). URL строится на
клиенте: `${origin}/p/${token}` — как в карточке сегодня.

## Ошибки

- GET/POST не ок — состояние ошибки в шите, кнопка «Повторить»; мутации — тост.
- `navigator.share` отклонён: `AbortError` — тихо; остальное — копирование + тост.
- Кнопка в hero у не-владельца не рендерится вовсе (не «задизейблена»).

## Проверка

- `bun run lint`, `bun run test` (новый тест `share-action`), `bunx tsc --noEmit`.
- Браузером (dev): кнопка только у владельца; шит; копирование; включение с нуля
  создаёт рабочую `/p/<token>`; фолбэк копирования там, где нет `navigator.share`.
