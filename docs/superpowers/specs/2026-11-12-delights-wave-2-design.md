## 2. Pull-to-refresh (глобальный)

Скролл в приложении оконный (`app-shell.tsx:269` корень без overflow; `<main>:484`
— padded-контейнер; единственные `overscroll-contain` — внутри шитов, они сами
глушат у себя). Точки интеграции:

- **Машина состояний** `src/lib/pull-refresh.ts` (чистая, с тестами):
  фазы `idle → pulling → armed → refreshing`; порог armed ≈ 72px; сопротивление
  растяжению; однократный тик хаптики при пересечении порога (armed один раз,
  обратный переход — сброс); release в `armed` → `refreshing`, иначе `idle`.
- **Хук** `src/hooks/use-pull-to-refresh.ts`: touch-события на window (passive,
  кроме активной фазы), активен только на coarse-pointer (`matchMedia("(pointer: coarse)")`),
  отключён при `scrollY > 0` и когда открыт оверлей/шит (у тех свой scroll-lock);
  `scroll-behavior: smooth` (globals.css:131) учтён при сбросе позиции.
- **Индикатор** `src/components/trip/pull-refresh-indicator.tsx`: узкая строка со
  спиннером под sticky-шапкой (шапка z-40 — индикатор z-40+, не полноэкранный);
  reduced-motion — без пружины.
- **Действие refresh**: `invalidateRouteData(qc)` (["route"]+["trip"]) + инвалидация
  `["expenses"]` и `["photos"]` — активная вкладка перечитывает своё (неактивные
  помечаются устаревшими и перечитаются при заходе). Хаптика «готово» по завершении.
- **CSS**: `overscroll-behavior-y: contain` на body (`globals.css`, блок body) —
  глушит нативный PTR браузера; в standalone PWA нативного нет, наш единственный.
- FAB (fixed z-40) перекрывает зону pull — индикатор под шапкой, не под пальцем.
