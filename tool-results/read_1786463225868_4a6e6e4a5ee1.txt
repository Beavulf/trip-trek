   117→   117→   117→### Fix: WebSocket not updating for other users
   118→   118→   118→**Root cause**: `use-websocket.ts` formed URL as `ws://hostname:3000` with explicit port. Through Caddy gateway (sandbox preview), client sees HTTPS without port → `window.location.port` empty → fallback to `3000` → `wss://hostname:3000` fails (Caddy doesn't expose 3000 directly).
   119→   119→   119→
   120→   120→   120→**Fix**: Changed to `window.location.origin` — WebSocket connects to same origin as page. Caddy proxies `/socket.io/` path correctly to localhost:3000.
   121→   121→   121→
   122→   122→   122→```ts
   123→   123→   123→// Было: ws://hostname:3000 (не работает через Caddy)
   124→   124→   124→const wsUrl = `${protocol}//${host}:${wsPort}`;
   125→   125→   125→
   126→   126→   126→// Стало: window.location.origin (работает через Caddy/HTTPS)
   127→   127→   127→const wsUrl = window.location.origin;
   128→   128→   128→```
   129→   129→   129→
   130→   130→   130→Also added `polling` as fallback transport (in case WebSocket blocked) and explicit `path: "/socket.io/"`.

   388→   388→   388→  if (status === "unauthenticated") {
   389→   389→   389→    router.push("/login");
   390→   390→   390→  }
   391→   391→   391→}, [status, router]);

   394→   394→   394→### Bug: Mobile browser crashes when taking/uploading photo
   395→   395→   395→**Root causes**:
   396→   396→   396→1. **Large photos (5-10MB)** — `exifr.parse(f)` reads full file into memory → crash
   397→   397→   397→2. **No compression** — original 4000x3000 photo uploaded as-is
   398→   398→   398→3. **Object URL leak** — `URL.createObjectURL(f)` never revoked → memory grows
   399→   399→   399→4. **Preview at full resolution** — `<img>` renders 8MB image
   400→   400→   400→5. **No processing indicator** — user doesn't know what's happening

   403→   403→   403→1. **Image compression via Canvas**: Resize to max 1920px, JPEG quality 0.8. Reduces 8MB → ~500KB
   404→   404→   404→2. **EXIF optimization**: `exifr.parse(f, { gps: true })` — only parses GPS segment (much faster, less memory)
   405→   405→   405→3. **Object URL cleanup**: `previewUrlRef` tracks URL, `URL.revokeObjectURL()` on cleanup/remove/unmount
   406→   406→   406→4. **Processing state**: `processing` state with loading overlay on preview + disabled buttons
   407→   407→   407→5. **Size validation**: Max 25MB before processing starts
