# Worklog — TripTrek China (приложение для путешествия в Китай)

## Project Overview
Приложение для группового путешествия 3 друзей в Китай (12 дней, 4 города: Гуанчжоу, Шэньчжэнь, Гонконг, Макао).
Цель: красивое, плавное, удобное приложение для отметки/просмотра/добавления воспоминаний в поездке.

## Стек (решения)
- Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui (предустановлено)
- Prisma + SQLite (вместо Supabase — проще, офлайн, не нужен внешний сервис)
- Leaflet + OpenStreetMap (вместо Mapbox — бесплатно, без API ключа)
- Framer Motion (анимации), Recharts (графики бюджета), Zustand (состояние)
- TanStack Query (server state), open-meteo API (погода, бесплатно без ключа)

## Функционал
1. Dashboard — прогресс поездки, бюджет, погода, текущий день
2. Itinerary — маршрут по дням с чек-листами, фото к местам
3. Map — интерактивная карта Leaflet с цветными пинами
4. Gallery — общая галерея фото с lightbox и фильтрами
5. Budget — траты, графики, расчёт долгов между друзьями
6. Rest & Chill — кафе/бары с рейтингом
7. Journal — дневник по дням
8. Quick-Add FAB — быстрое добавление фото/траты/заметки
9. Participants — 3 друга с цветами, переключатель текущего пользователя
